## Dependencies

## Description
`er-customvehicle` currently is a **Vehicle Mods Customization** menu and it would only work for administration permissions. <br />
You can open the *UI* Menu through `/custom`. <br />
## Installation
First of all download the script [here](https://en.wikipedia.org/wiki/N/A) <br />
Place it in `resources` folder then ensure it right after `menuv`'s execution <br />
e.g.
```bash
ensure menuv
ensure qb-customvehicle
```
